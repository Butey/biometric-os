# Дозу рекомендует модель, рамки держит код

Повысить, удержать или снизить дозу предлагает модель по данным весов и журналу побочных эффектов, с оговоркой, что дозу подтверждает врач. Код не выбирает дозу, но жёстко держит рамки из карты препарата: новая доза в расписании — ступень лестницы титрации, не выше максимума, повышение только на соседнюю ступень и не раньше минимального срока; после перерыва в терапии больше двух недель — не выше прежней дозы. Выход за рамки возможен только с пометкой «по назначению врача»; фактический приём записывается всегда.

Это осознанное исключение из принципа «числа считает код»: решение о дозе зависит от переносимости и контекста, которые код не видит, а ошибка, которая стоит здоровья, — перепрыгнуть ступень или превысить максимум — ловится детерминированно.

## Considered Options

- **Дозу считает код по правилам.** Переносимость (тошнота, рвота) приходит из разговора и не сводится к порогам.
- **Модель без рамок, как было.** Лестницы в картах не было, модель называла дозы по памяти, а `pharma schedule` принимал любое число.
- **Рамки только как предупреждение.** Модель может проигнорировать предупреждение.

## Consequences

- Побочные эффекты хранятся в отдельном журнале (дата, симптом, тяжесть), без привязки к препарату: окно переписки — 20 сообщений, а дозу меняют не чаще раза в четыре недели.
- Карта препарата — общий справочник (синонимы, лестница, фармакокинетика, источник); доза и расписание — личные данные человека.
- Для препарата без карты модель готовит черновик только по официальным API (инструкции FDA, ClinicalTrials.gov) со ссылками; админ получает уведомление в Telegram и одобряет или правит в панели. До одобрения — только учёт приёма.
- Для незарегистрированных препаратов (ретатрутид) полной лестницы в структурированных данных нет: админ дописывает её по протоколу исследования.
