# ПРОТОКОЛ ПРЕОБРАЗОВАНИЯ ДАННЫХ (ETL)

**Входные данные:** Строки из экспорта приложения (CSV/Excel).
**Задача:** Привести данные к структуре `body_metrics.csv` без потери точности.

### 1. Маппинг столбцов (Mapping)
Обязательно сопоставить следующие поля:
- Дата/Время -> `timestamp` (Формат: DD/MM/YYYY HH:MM:SS)
- Вес(kg) -> `weight_kg`
- Содержание жира(%) -> `fat_pct`
- ИМТ -> `bmi`
- Скелетные мышцы(%) -> `muscle_mass_pct`
- Мышечная масса(kg) -> `muscle_mass_kg`
- Белок(%) -> `protein_pct`
- Скорость обмена веществ(kcal) -> `bmr_kcal`
- Висцеральный жир -> `visceral_fat`
- Содержание воды(%) -> `water_pct`
- Костная масса(kg) -> `bone_mass_kg`
- Метаболический возраст -> `metabolic_age`

### 2. Правила нормализации
- Символы "- -" или "0" преобразовывать в `0` (или `NULL` для SQL).
- Десятичный разделитель — точка (`.`).
- Если зафиксирован только вес (биоимпеданс не сработал), оставить вес, остальные поля заполнить `0`.

### 3. Формат вывода для копирования в бота
Выводить в формате CSV:
`timestamp,weight_kg,fat_pct,bmi,muscle_mass_pct,muscle_mass_kg,protein_pct,bmr_kcal,visceral_fat,water_pct,bone_mass_kg,metabolic_age`
