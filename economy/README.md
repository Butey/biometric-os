# Экономика токенов Health Agent System

Данный каталог содержит комплексный аудит расхода токенов бота, ценовой анализ моделей языковых сетей (Claude 3.5/3.7 Sonnet, Haiku, Opus), замеры на основе реальной базы данных `health.db` (2 510 сообщений), а также готовые инженерные планы по внедрению Prompt Caching и сокращению вызовов модели.

---

## 📊 Главные цифры и факты

1. **Расход токенов в день (из реальной базы):**
   * **Обычный день:** **~2,0 млн токенов/день** (1,96 млн input, ~28k output, ~40 сообщений пользователя, ~76 обращений к LLM).
   * **Активный день (последняя неделя):** **~2,8 млн токенов/день** (2,74 млн input, ~44k output, ~55 сообщений, ~107 вызовов LLM).
   * **Пиковый день (активное меню, разбор рациона):** **до 7,85 млн токенов/день** (142 сообщения, 299 вызовов LLM).
   * **Спокойный день (только вес и 2–3 приёма пищи):** **~300k – 500k токенов/день**.

2. **Анатомия одного запроса (почему уходит так много):**
   * **98.6% токенов — это Input (входные токены).**
   * **Базовый контекст каждого запроса — 23 312 токенов:**
     * Системный промпт (`Core/system_promt.md`): **9 136 токенов** (39.2%)
     * Индекс базы знаний (`Knowledge`): **790 токенов** (3.4%)
     * Спецификации 35 инструментов (`bot/registry.py`): **13 386 токенов** (57.4%)
   * При логировании еды/воды бот делает **два вызова LLM подряд** (Шаг 1: вызов тула $\rightarrow$ Шаг 2: подтверждение), расходуя суммарно **~51 600 токенов на одно сообщение пользователя**.

3. **На сколько хватает 15 млн токенов:**
   * **В сообщениях:** **~300 сообщений пользователя**.
   * **По времени без кэширования:**
     * При активном темпе (~2.8M/день): **на ~5.4 дня** (~5 дней).
     * При среднем темпе (~2.0M/день): **на ~7.5 дней** (1 неделя).
     * В пиковом режиме (~7.8M/день): **на 2 дня**.
     * В экономном режиме (~500k/день): **на ~30 дней** (1 месяц).
   * **С включённым Prompt Caching (скидка 90% на базу):**
     * 15 млн токенов растягиваются на **~40–45 дней (1.5 месяца)** при обычном темпе.

## 💰 Сравнение стоимости моделей (Claude Sonnet vs Haiku vs Opus)

| Модель | Тариф (Input / Output за 1M) | Без кэширования (обычный день) | С Prompt Caching (−90% на базу) | Стоимость в месяц (с кэшем) |
| :--- | :--- | :--- | :--- | :--- |
| **Claude 3.5 / 3.7 Sonnet** | $3.00 / $15.00 | $6.30 / день | **$1.25 – $1.35 / день** | **~$37 – $40 / мес** *(вместо $190)* |
| **Claude 3.5 Haiku** | $0.80 / $4.00 | $1.68 / день | **$0.30 – $0.35 / день** | **~$9 – $10 / мес** *(вместо $50)* |
| **Claude 3 Opus** | $15.00 / $75.00 | $31.50 / день | **$6.50 – $7.50 / день** | **~$195 – $225 / мес** *(вместо $940)* |

> **Рекомендация:** Для повседневного чата и парсинга рациона идеален **Claude 3.5 Haiku** (быстрый, дешевый, $10/мес). Для глубокого анализа и консилиума — **Claude 3.5/3.7 Sonnet** с включенным Prompt Caching ($37–40/мес). Использовать Opus для рутинного логирования экономически нецелесообразно.
