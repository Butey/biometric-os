## Чего нет нигде

1. **Углеводный минимум 150–165 г/сут** — макро-расчёт автоматический (остаток после белка/жира), жёсткого минимума углеводов не установлено.
2. **FSM states в статус-баре** — реализован четырёхстрочный status_bar без индикации fsm_state.
3. **RECOVERY_SICK_LEAVE** — состояние отсутствует в коде и документации.
4. **Zone 2 120–135 уд/мин, потолок 140; VR Чт/Сб** — спецификация пульсовых зон не реализована.
5. **Абсолютный стоп LBM 75.0 кг** — вместо этого используются относительные гардрейлы (LBM_RATIO, LBM_DRIFT, FFMI_FLOOR).
6. **Лабораторные маркеры: GGT, ЩФ, цистатин C, мочевая кислота, ТТГ, свT3/свT4, тестостерон, ГСПГ, гематокрит/RBC, ApoB** — отсутствуют в labs.py MARKERS.
