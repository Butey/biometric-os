# Многопользовательский режим: разбор и решения

Инвентарь — Haiku (`inventory.md`), разбор и приоритеты — Sonnet (текст агента не
смог записать сам, здесь сжатая версия), решения и распределение — оркестратор.

Модель доступа (требование пользователя): один администратор
(`config.yaml admin.telegram_admin_ids`), пользователи — разные звонящие в Telegram,
администратор одобряет их командой.

## Ложные срабатывания инвентаря

- «SQL без user_id — 0»: неверно, пропуски в `_admin_*` хелперах plugin/tools.py (MU-4…7).
- `date.today()` в scripts/: не баг — notify.py передаёт TZ человека дочернему процессу.
- `params.get("user_id", 1)`: из-под бота недостижимо — звонящий выставляется во всех
  путях входа (текст, файлы, фото, слэш-команды), модель не может подменить user_id.
- Комментарии про возраст 34 в config.yaml: код считает возраст из профиля.
