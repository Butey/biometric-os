# Метрики: как читать цифры и где приборы врут

Про то, какому числу можно верить и насколько. Собрано по ходу работы с
реальными данными в августе 2026 — почти каждый пункт всплыл потому, что
сначала был прочитан неправильно.

Общее правило: **отдельный замер не значит почти ничего, значение имеет
сглаженный тренд.**

## Весы: собственный шум прибора

Разброс между замерами в одно и то же утро, реальные данные:

```
22.08  08:43 → 121.0     08:59 → 120.5     разброс 0.5 кг за 16 минут
20.08  09:23 → 121.8     19:14 → 122.7     разброс 0.9 кг
23.08  08:22 → 120.8     08:36 → 120.7     разброс 0.1 кг
```

**0.5 кг — это ровно та величина, которую прибор выдаёт, если слезть и встать
обратно.** Изменение такого размера физически не может быть сигналом: оно не
отличимо от погрешности.

Практика: перед разговором о «плюс полкило» сначала посмотреть, укладывается
ли это в собственный разброс весов.

## Сглаживание веса

Считать так: **медиана внутри дня** (гасит шум прибора), затем **среднее по
7 дням**, и сравнивать с предыдущими 7 днями.

```
18–24.08: 121.63 кг
11–17.08: 123.06 кг
        → −1.43 кг/нед = 1.17%/нед   при пороге 1.00%
```

Соседние дни не сравнивать никогда. Колебания ±1–2 кг в сутки — вода,
гликоген, натрий. Килограмм жира это 7700 ккал, за сутки его не потерять и
не набрать.

Пример цены ошибки: по соседним дням выходило 1.35 кг/нед, по сглаженному
окну — 0.92 кг/нед. Разница в полтора раза на пустом месте.

Тренд не статичен: в течение августа он вырос с 0.76%/нед до 1.17%/нед.
Цифру надо пересчитывать, а не помнить.

## Биоимпеданс

**Систематически завышает тощую массу на +2.8 ± 2.1 кг** и занижает жировую
на −2.9 ± 2.0 кг против DXA (PMC11649400, 2024). При ожирении избыток
внеклеточной жидкости усиливает перекос.

Отсюда:

- по одному замеру состава тела судить нельзя, только по сглаженному тренду;
- абсолютное число тощей массы держать как ориентир, не как факт.

### Прибор умеет противоречить себе

Реальный случай, 24→25.08:

```
             24.08    25.08
вес, кг       121.4 →  122.0    +0.6
жир %          34.6 →   34.8    +0.2
мышцы, кг      75.4 →   75.7    +0.3
вода %         47.2 →   47.1    −0.1
висц. жир        17 →     18    +1
```

Жир и мышцы «выросли» одновременно за одну ночь. Так не бывает: +0.2 кг жира
требуют около 1540 ккал сверх нормы, а съедено было 935 при расходе ~2500.
Прибор увидел лишние 600 г и разложил их по всем компартментам, потому что не
умеет распознавать воду.

Висцеральный жир 17→18 — один шаг целочисленной шкалы, минимально возможное
изменение. Читать в нём нечего.

**Диапазоны за 10 дней:** мышцы 75.3–75.7 (размах 0.4), сухая 79.3–79.7
(0.4), жир % 34.1–35.3 (1.2). Ничего структурного не двигалось, при том что
вес гулял на полтора килограмма.

## Талия

**Независимый от биоимпеданса сигнал.** Снимается за десять секунд, не
зависит от гидратации так, как процент жира. Просить мерить раз в неделю.

WHR при последнем замере 1.04–1.05 при пороге 0.90 — абдоминальное ожирение,
гард срабатывает.

## Фитнес-часы

**Калории завышены примерно втрое.** Часы отчитались о 1159 ккал, расчётно
выходит ~372. В расчёт цели такие цифры не брать вовсе.

Брать оттуда можно: шаги, пульс покоя, время сна как факт. Нельзя:
калории, «оценку сна», стадии сна.

В коде это учтено скидкой: калории тренировки из TCX умножаются на 0.75, и
ещё на 0.9, если пульса в файле нет.

## Сон

- Дата ночи = **дата утра пробуждения**.
- Стадии сна упоминать только если прибор дал число, и выводов на них не
  строить — бытовые трекеры меряют стадии плохо.
- Проприетарную «оценку сна» целевой метрикой не считать.
- Ночь короче 6 часов — снизить объём тренировки, но не отменять.

## Формулы BMR: что реально считает код

Используется **максимум из двух**: Katch-McArdle по тощей массе и
Mifflin-St Jeor по массе тела.

```
Katch(FFM 79.6)  = 2089 ккал
Mifflin(122 кг)  = 2211 ккал
берётся max      = 2211 ккал
```

**Расхождение с документацией.** `Docs/calorie_model.md` заявляет, что
Mifflin отклонён из-за отсутствия роста и возраста в данных. Профиль с тех
пор пополнился, код перешёл на максимум из двух, спека не обновлена. При
чтении той спеки это надо держать в голове.

BMR 2211 — это **формула, а не замер**. Отдельного измерения расхода покоя
не делалось.

## Адаптивный TDEE

```
TDEE_факт = средний_приход_за_N_дней + (Δвес_за_N_дней × 7700 / N)
```

Требует еды, залогированной **минимум 11 дней из 14**. Иначе возвращает
`None`, и калибровка замораживается, а не подгоняется по огрызку данных.

На текущих данных молчит: дней записано меньше порога.

Пока калибровки нет, расход оценивается как `BMR × 1.20` — коэффициент для
дня без тренировки, только бытовая активность. Тренировочный коэффициент
(1.36) сюда ставить нельзя: занятия приходят отдельно из TCX и посчитались бы
дважды.

## Пробел в данных против нуля

Отдельная категория ошибок: сумма 0 может означать «съедено ноль», а может —
«поле не заполнено». Для клетчатки это выяснилось на живых данных: у всех
продуктов за 24.08 поле пустое, а сводка показывала «0/25 г» с пустой полосой
прогресса — читается как «не съел ни грамма», хотя квашеная капуста 200 г и
бородинский хлеб 104 г дают около 10 г.

Правило: если известность значения отслеживается отдельным признаком —
показывать «нет данных», а не ноль. Пустая полоса прогресса на пробеле в
данных врёт.

## Занижение прихода: как поймать без дневника

Проверка на непротиворечивость:

```
если  средний_приход + дефицит_из_тренда  <  BMR
то    дневник недосчитывает
```

TDEE физически не может быть ниже BMR. На этих данных проверка дала около
400 ккал/сут недоучёта. Литературная медиана — 605.

## Что показывает прогресс лучше всего

По убыванию надёжности:

1. **Рабочие веса и повторения** — сила падает раньше, чем это увидит любой
   прибор.
2. **Окружность талии** — независима от биоимпеданса.
3. **Сглаженный вес за 7 дней** — шум гасится, тренд виден.
4. Состав тела по биоимпедансу — только тренд, только на длинном окне.
5. Отдельный замер веса — почти ничего.
6. Калории с часов — не показывает ничего.
