## 1. Протоколы доказательной поведенческой терапии ожирения и РПП

### 1.1. CBT-E (Christopher G. Fairburn): Регулярное питание как якорь и дифференциация нарушений

#### Трансдиагностическая модель и когнитивные механизмы срыва
В основе модели Кристофера Фейрберна (Fairburn, 2008) лежит концепция **сверхценности веса и формы тела** (*over-evaluation of shape and weight*), которая порождает жесткий диетический контроль (*rigid dietary restraint*).

```
┌────────────────────────────────────────────────────────┐
│      Сверхценность веса, формы тела и контроля         │
└───────────────────────────┬────────────────────────────┘
                            ▼
┌────────────────────────────────────────────────────────┐
│     Жесткие диетические правила и дефицит калорий      │
└─────────────┬───────────────────────────┬──────────────┘
              │                           │
  [Физиологический голод]       [Когнитивная уязвимость]
              │                           │
              └─────────────┬─────────────┘
                            ▼
┌────────────────────────────────────────────────────────┐
│        Единичное отклонение / Лапс (Lapse)             │
│            (съел «запрещенный» продукт)                │
└───────────────────────────┬────────────────────────────┘
                            ▼
┌────────────────────────────────────────────────────────┐
│    Дихотомическое мышление («Все или ничего»)          │
│        Abstinence Violation Effect (AVE)               │
│        «Диета сорвана — гори сарай, ешь всё»           │
└───────────────────────────┬────────────────────────────┘
                            ▼
┌────────────────────────────────────────────────────────┐
│   Объективный или субъективный срыв (Binge Eating)     │
└───────────────────────────┬────────────────────────────┘
                            ▼
┌────────────────────────────────────────────────────────┐
│       Стыд, вина, страх набора веса, паника            │
└───────────────────────────┬────────────────────────────┘
                            ▼
┌────────────────────────────────────────────────────────┐
│    Компенсация (голодание, спорт, ужесточение рамок)   │
└───────────────────────────┬────────────────────────────┘
                            │
                            └────► Возврат в начало цикла
```

1. **Дихотомическое мышление (Dichotomous / All-or-Nothing Thinking)**:
   - В психологии зависимости и РПП описан **Abstinence Violation Effect (AVE)** (Marlatt & Gordon): нарушение жесткого правила воспринимается не как дельта в 150 ккал, а как тотальное крушение идентичности («я безвольный», «день испорчен»).
   - Разрушение правила провоцирует растормаживание (*disinhibition*): «Если плотина прорвана, количество воды уже не имеет значения».

2. **Регулярное питание как базовый якорь (Planned Regular Eating)**:
   - **Протокол CBT-E**: строго фиксированная сетка — **3 основных приема пищи + 2–3 запланированных перекуса** с интервалом между контактами с едой **не более 3–4 часов** (например: 08:30 — 12:00 — 15:30 — 19:00 — 21:30).
   - **Золотое правило CBT-E**: *«Регулярность важнее состава и калорийности»* (*Regularity over content*). На этапе стабилизации поведения запрещается оптимизировать калораж до тех пор, пока не закреплена предсказуемость тайминга.
   - **Физиологический механизм якоря**:
     - Предотвращает падение гликемии ниже базального порога и компенсаторный скачок грелина.
     - Ликвидирует состояние «хищнического» голода, при котором дорсолатеральная префронтальная кора (DLPFC) отключается в пользу лимбической системы.
     - Заранее планируемый следующий прием пищи (через 3 часа) дает мозгу когнитивную опору: «Мне не нужно наедаться впрок, еда будет доступна через 180 минут».

3. **Дифференциация: Пищевой хаос vs Диетические ограничения**:

| Критерий | Пищевой хаос (Food Chaos) | Диетические ограничения (Dietary Restraint) |
| :--- | :--- | :--- |
| **Феноменология** | Нерегулярность, пропуски еды из-за дел, «кусочничество» (*grazing*), еда на ходу, реакция на внешние стимулы (вид, запах еды). | Жесткие запреты на группы продуктов («сахар — яд», «углеводы до 12»), лимиты калорий ниже BMR, наказание голодом за вчерашнее. |
| **Когнитивный паттерн** | Дефицит планирования, слабая интероцепция (не чувствует насыщения, пока желудок не растянут). | Дихотомия («чистая» vs «грязная» еда), постоянный подсчет, страх потери контроля. |
| **Триггер срыва** | Физиологическое истощение к вечеру на фоне пропущенного обеда $\to$ автоматический неконтролируемый зажор. | Случайный контакт с «запретной едой» $\to$ AVE («сорвался — доем торт целиком»). |
| **Тактика агента** | **Структурная опора**: жесткие временные слоты, напоминания о еде, шаблоны готовой корзины (`pantry`), фокус на регулярности. | **Когнитивная гибкость**: легализация продуктов, отказ от жестких списков запретов, деэскалация глубины дефицита, ликвидация компенсаций. |

### 1.2. ACT (Acceptance and Commitment Therapy): Серфинг побуждений и когнитивное разделение

В отличие от классического CBT, пытающегося оспорить мысль («Действительно ли этот торт тебе нужен?» — что часто усиливает руминацию), ACT учит менять **отношение** к мыслям и телесным побуждениям через принятие (*Acceptance*) и разделение (*Defusion*).

#### A. Техника «Urge Surfing» (Серфинг волны тяги — Alan Marlatt / ACT)
- **Нейробиология тяги**:
  - Тяга к гипервкусной пище (*craving*) — это кратковременный фазический всплеск дофамина в мезолимбическом тракте (*nucleus accumbens*), запущенный условным стимулом (триггером).
  - Кривая тяги подобна морской волне: постепенное нарастание $\to$ острый пик (длится **10–15 минут**) $\to$ физиологический спад и угасание при отсутствии подкрепления.
  - Попытка подавить тягу силой воли (*thought suppression*) вызывает парадоксальный «эффект рикошета» (Daniel Wegner, Ironic Process Theory).
- **Пошаговый диалоговый протокол для интерфейса**:
  1. **Заметить и соматизировать (Notice & Locate)**: «Где именно в теле живет это желание прямо сейчас? Горло, слюноотделение, сжатие в груди, пустота в желудке?»
  2. **Заземление (Grounding & Breath)**: 3 цикла медленного дыхания (вдох на 4, выдох на 6 счетов) для снижения симпатического тонуса.
  3. **Наблюдение за волной (Track the Crest)**: «Представь эту тягу как волну. Оцени ее силу от 1 до 10. Сейчас она на гребне. Волне не нужно сопротивляться — мы просто стоим на доске и наблюдаем за ней».
  4. **Таймер экспозиции (15-Minute Rule)**: «Поставь таймер на 15 минут. Если через 15 минут физиологическая потребность останется — мы осознанно включим порцию в план. Но следующие 15 минут мы даем волне разбиться о берег».

#### B. Когнитивное разделение (Cognitive Defusion)
Цель — разрушить **когнитивное слияние** (*cognitive fusion*), когда мысль воспринимается как объективная реальность или безусловный приказ к действию.

- **Лингвистические техники расцепления в диалоге бота**:
  - *Техника маркировки процесса*: замена формулировки *«Мне срочно нужна шоколадка»* на *«Я замечаю, что мой мозг генерирует мысль о шоколадке»*.
  - *Техника «Благодарность уму»*: *«Спасибо, мозг, за заботу. Ты считаешь, что я устал и мне нужна быстрая глюкоза. Я услышал это предложение, но выбор за мной»*.
  - *Метафора «Пассажиры в автобусе»*: «Мысли о еде, тревога и импульс все бросить — это шумные, агрессивные пассажиры твоего автобуса. Они кричат: "Поворачивай к холодильнику!". Но водитель автобуса — ты, и руки на руле у тебя. Пассажиры могут шуметь, но автобус едет по твоему маршруту».
  - *Метафора «Всплывающие уведомления»*: «Тяга — это спам-баннер в браузере. Если кликать по каждому баннеру, система зависнет. Мы видим баннер, признаем его присутствие, но продолжаем читать страницу».

#### C. Разделение гедонистического и гомеостатического голода
- **Homeostatic Hunger (биологический)**: развивается медленно (>3.5–4 ч после еды), ощущается в эпигастрии (урчание, легкая слабость), нейтрален к типу еды (человек согласен съесть яйцо, суп или гречку).
- **Hedonic Hunger (гедонистический / "food noise")**: вспыхивает мгновенно, специфичен («хочу именно соленое/хрустящее/шоколадное»), локализован во рту и голове, провоцируется стрессом, скукой или зрительным стимулом.
- **Связка с ценностями (Committed Action)**: «Съесть этот десерт на эмоциях приблизит тебя к тому самочувствию и форме, ради которых ты начинал, или это минутная плата за избегание неприятной эмоции?».

### 1.3. Мотивационное интервьюирование (Miller & Rollnick, OARS) в текстовых диалогах

Главная опасность для автоматизированного health-агента — впасть в **менторский тон**, читать нотации или проявлять токсичный позитив. Это мгновенно активирует **психологическую реактивность** (*Psychological Reactance*, Brehm, 1966) — защитное сопротивление директивному давлению.

```
                      ДИАЛОГОВАЯ СЕТКА OARS
┌──────────────────────────────┬──────────────────────────────┐
│  O — Open-Ended Questions    │  A — Affirmations            │
│  (Открытые вопросы)          │  (Валидация усилий)          │
├──────────────────────────────┼──────────────────────────────┤
│  R — Reflective Listening    │  S — Summarizing             │
│  (Отражающее слушание)       │  (Структурное резюме)        │
└──────────────────────────────┴──────────────────────────────┘
```

#### Реализация протокола OARS в текстовом интерфейсе:

1. **O — Open-Ended Questions (Открытые вопросы)**:
   - *Запрещено*: закрытые допросы («Ты взвесился?», «Опять переел?», «Будешь соблюдать план?»).
   - *Паттерн*: вопросы, пробуждающие субъектность и рефлексию:
     - «Что сегодня помогло выдержать интервал между обедом и ужином?»
     - «Как меняется твое состояние, когда пауза между приемами затягивается дольше 5 часов?»
     - «Если посмотреть на вечер со стороны: в какой именно момент контроль начал ускользать?»

2. **A — Affirmations (Валидация автономии и усилий)**:
   - *Правило SPEC.md*: **запрещены** инфантилизирующие похвалы («Молодец!», «Отлично!», «Умница!», каскады эмодзи 🎉👏).
   - *Доказательный подход*: признание конкретных фактов преодоления, стойкости и честности данных:
     - «Ты залогировал переедание в 1200 ккал полностью, не скрывая продукты. Это требует смелости и дает нам объективные данные вместо иллюзий».
     - «Несмотря на тяжелый дедлайн на работе, ты сохранил белковый каркас дня — это надежный поведенческий навык».

3. **R — Reflective Listening (Отражающее слушание)**:
   - *Простое отражение (Simple)*: точный возврат факта без искажений и оценок:
     - *Юзер*: «Пришел домой уставший, увидел пиццу и просто смел три куска, даже вкуса не понял».
     - *Бот*: «Усталость к вечеру была настолько высокой, что тело потребовало быстрой энергии раньше, чем включился осознанный выбор».
   - *Сложное отражение амбивалентности (Complex / Double-sided)*:
     - *Бот*: «С одной стороны, в моменте пицца сняла острое напряжение после тяжелого дня. С другой стороны, сейчас ты чувствуешь разочарование и тяжесть, потому что для тебя важно двигаться к стабильному весу без качелей».

4. **S — Summarizing (Обобщение и возврат контроля)**:
   - Сборка картины в нейтральный отчет и передача руля пользователю:
     - *Бот*: «Давай сведем картину: за последние 4 дня дефицит составил 3800 ккал при сне менее 6 часов. Вечером включился физиологический откат. Данные внесены, метаболический баланс за неделю скорректирован. Как ты хочешь выстроить завтрашний завтрак, чтобы вернуть стабильность?».

#### Протокол разбора срыва (Lapse Debriefing Protocol)
Срыв — это **не моральный провал**, а **клинический маркер декомпенсации протокола**:
1. **Нормализация и дестигматизация**: «Срыв при глубоком снижении веса — это закономерная реакция биологии на накопленный дефицит и усталость, а не поломка характера».
2. **Анализ цепи событий (Behavioral Chain)**: выявление точки невозврата (дефицит сна $\to$ пропуск обеда $\to$ триггерная обстановка $\to$ импульсивная покупка $\to$ изолированное поедание).
3. **Запрет компенсаторного наказания**: категорический запрет «отрабатывать» срыв голодовкой или кардио на следующий день (компенсация гарантирует повторный срыв через 48–72 часа).

## 2. Цифровые биомаркеры срывов и диетической усталости (Adherence Telemetry)

### 2.1. Паттерны задержки логирования (Logging Latency) и пропуски приемов

Телеметрия поведения пользователя в чат-интерфейсе позволяет выявлять надвигающийся срыв за 12–36 часов до его манифестации.

#### Метрика задержки ввода (Logging Latency $\Delta t_{\text{log}}$)
$$\Delta t_{\text{log}} = t_{\text{record}} - t_{\text{eaten}}$$
где $t_{\text{record}}$ — серверное время отправки сообщения/вызова инструмента `log_food`, $t_{\text{eaten}}$ — фактическое время приема пищи, указанное пользователем.

```
Классификация паттернов телеметрии:
├─ 1. Real-time logging (Δt < 30-45 мин)   ──► Высокий когнитивный контроль, нулевой дрейф
├─ 2. Delayed logging (2 ч < Δt < 6 ч)     ──► Нарастающая занятость, фоновое сопротивление
├─ 3. Retrospective Dumping (ночью/утром)  ──► Диетическое избегание, потеря точности на 30-50%
└─ 4. Selective Omission (Ghosting)        ──► Острый стыд после переедания, предвестник срыва
```

- **Ретроспективный «дамп» (End-of-day / Next-day Dumping)**:
  - Когда пользователь перестает вносить еду по факту и вносит все приемы разом перед сном (или на следующее утро), погрешность оценки порций возрастает на 30–50% (*underreporting bias*).
  - Увеличение скользящей средней задержки $\overline{\Delta t_{\text{log}}}$ за 3 дня более чем в 2.5 раза — **ранний цифровой биомаркер диетической усталости** (*diet fatigue*).
- **Паттерн селективного пропуска (Selective Logging Omission)**:
  - Пропуск слота `lunch` или `snack` при наличии последующего высококалорийного `dinner` (>50% суточного калоража) указывает на компенсаторную гиперфагию.
  - Межпищевой интервал $> 5.5$ часов в период бодрствования — прямой триггер вечерней утраты контроля.

### 2.2. Накопленный дефицит калорий (>30–40% от TDEE более 4 дней подряд)

#### Нейроэндокринная декомпенсация жесткого дефицита
Эволюционно организм человека оптимизирован на выживание в условиях голода. Длительный дефицит $>35\%$ от TDEE включает защитный каскад:

```
Хронический дефицит >35% TDEE (≥4 дней подряд)
    │
    ├──► 1. Падение лептина (>50% за 72 ч) ──► Снятие тормоза с AgRP/NPY в гипоталамусе
    │
    ├──► 2. Подавление конверсии T4 → T3   ──► Рост реверсивного rT3, снижение BMR
    │
    ├──► 3. Снижение симпатического тонуса ──► Обвал NEAT (нетренировочной активности)
    │
    ├──► 4. Истощение запасов гликогена    ──► Кортизоловый подъем, мышечный катаболизм
    │
    └──► 5. Ego Depletion (Baumeister)     ──► Префронтальный тормозной паралич
```

- **Физиологический откат**: волевой контроль (префронтальная кора) истощается как метаболический ресурс. Орексигенный драйв нейропептида Y (NPY) и AgRP превосходит силу воли, генерируя компульсивный голод с фокусом на углеводно-жировые калорийные бомбы.
- **Математическая формализация дефицита**:
  $$D_{\text{day}} = \text{TDEE}_{\text{adaptive}} - \text{Intake}_{\text{kcal}}$$
  $$R_{\text{deficit}} = \frac{D_{\text{day}}}{\text{TDEE}_{\text{adaptive}}}$$
  $$D_{\text{cum}}(N) = \sum_{k=0}^{N-1} D_{\text{today}-k}$$
  - Если $R_{\text{deficit}} \ge 0.35$ в течение $N \ge 4$ последовательных дней (или $D_{\text{cum}}(5) \ge 3500\dots 4000$ ккал), риск неконтролируемого срыва приближается к **критической отметке (0.85–0.92)**.

### 2.3. Сокращение сна (< 6 часов) как триггер грелинового всплеска

Клинические исследования (Spiegel et al., 2004; Tasali et al., 2022; Taheri et al., 2004) демонстрируют драматическое влияние депривации сна на метаболизм:

1. **Гормональный сдвиг**:
   - Сон $< 6$ часов в течение всего одной ночи приводит к:
     - **Повышению циркулирующего ацилированного грелина на $+22\dots+28\%$** (мощнейший стимулятор аппетита, вырабатываемый клетками дна желудка).
     - **Падению лептина на $-18\%$** (гормон насыщения из адипоцитов).
     - Отношение Грелин/Лептин сдвигается в сторону непрерывного поиска пищи.
2. **Эндоканнабиноидная гиперактивация (2-AG)**:
   - Исследования Hanlon et al. (2016): при недосыпе уровень 2-арахидоноилглицерола (2-AG) остается патологически повышенным на протяжении всего дня (в норме он падает после полудня). Это запускает гедонистический жор (*the munchies*), идентичный каннабиноидной стимуляции.
3. **Нейровизуализация (fMRI)**:
   - Снижение связности между префронтальной корой и лимбической системой.
   - Гиперреактивность островковой доли (*insula*) и миндалевидного тела на зрительные стимулы высококалорийной пищи.
   - Итог: **спонтанный профицит потребления на $+350\dots+500$ ккал/сутки**, причем 85% этого избытка приходится на простые сахара и насыщенные жиры в вечернее время.

### 2.4. Binge Risk Triad Score (BRTS): Математическая спецификация

Для детерминированного прогнозирования срыва в `health_core` разработана комплексная модель оценки — **Binge Risk Triad Score (BRTS)**, нормализованная в диапазоне **[0, 100] баллов**.

```
                           BINGE RISK TRIAD
                     ┌───────────────────────────┐
                     │     BRTS: 0 - 100         │
                     └─────────────┬─────────────┘
          ┌────────────────────────┼────────────────────────┐
          ▼                        ▼                        ▼
┌───────────────────┐    ┌───────────────────┐    ┌───────────────────┐
│ S_deficit (40%)   │    │ S_sleep (30%)     │    │ S_behavior (30%)  │
│ Накопленный        │    │ Продолжительность │    │ Задержка логов,   │
│ дефицит калорий   │    │ и долг сна        │    │ пропуск белка     │
└───────────────────┘    └───────────────────┘    └───────────────────┘
```

#### Формула расчета:
$$\text{BRTS} = w_1 \cdot S_{\text{deficit}} + w_2 \cdot S_{\text{sleep}} + w_3 \cdot S_{\text{behavior}}$$
где весовые коэффициенты:
$$w_1 = 0.40, \quad w_2 = 0.30, \quad w_3 = 0.30$$

---

#### 1. Компонент метаболического дефицита ($S_{\text{deficit}} \in [0, 100]$):
Анализирует скользящее окно в 5 дней ($k = 1\dots 5$).
Пусть $D_{\text{cum}} = \sum_{k=1}^5 \max(0, \text{TDEE}_k - \text{Intake}_k)$.
Пусть $N_{\text{extreme}}$ — количество дней из последних 5, когда $\text{Intake}_k < 0.65 \cdot \text{TDEE}_k$.

$$S_{\text{deficit}} = \text{clamp}\left( \frac{D_{\text{cum}}}{4000} \cdot 60 + \frac{N_{\text{extreme}}}{4} \cdot 40, \; 0, \; 100 \right)$$
*Если фактический лог за последние дни отсутствует, $S_{\text{deficit}}$ деградирует до 0 (принцип SPEC.md: нет данных — нет суждения).*

---

#### 2. Компонент сна ($S_{\text{sleep}} \in [0, 100]$):
Анализирует сон последней ночи ($t_{\text{sleep\_last}}$ в минутах) и средний сон за 3 дня ($t_{\text{sleep\_avg3}}$).
Порог нормы — **420 минут (7 часов)**, критический порог — **360 минут (6 часов)**.

$$S_{\text{sleep}} = \text{clamp}\left( \frac{420 - t_{\text{sleep\_last}}}{420 - 300} \cdot 70 + \max\left(0, \frac{420 - t_{\text{sleep\_avg3}}}{420 - 330}\right) \cdot 30, \; 0, \; 100 \right)$$
*При отсутствии записи сна прошлой ночью компонент принимает значение по умолчанию 20 (нейтральный риск).*

---

#### 3. Компонент поведенческой телеметрии ($S_{\text{behavior}} \in [0, 100]$):
Складывается из трех цифровых субмаркеров:
1. **Белок на завтрак ($P_{\text{bf}}$)**: белок стимулирует PYY и GLP-1, притупляя аппетит на весь день. Порог — 25 г.
   $$F_{\text{protein}} = \begin{cases} 40, & \text{если } P_{\text{bf}} < 15\text{ г или завтрак пропущен} \\ 20, & \text{если } 15\text{ г} \le P_{\text{bf}} < 25\text{ г} \\ 0, & \text{если } P_{\text{bf}} \ge 25\text{ г} \end{cases}$$
2. **Задержка логирования ($\Delta t_{\text{log}}$ за последние 24 часа)**:
   $$F_{\text{latency}} = \begin{cases} 35, & \text{если } \Delta t_{\text{log}} > 6\text{ ч (дамп перед сном)} \\ 20, & \text{если } 3\text{ ч} < \Delta t_{\text{log}} \le 6\text{ ч} \\ 0, & \text{если } \Delta t_{\text{log}} \le 3\text{ ч (потоковый ввод)} \end{cases}$$
3. **Межпищевой разрыв ($G_{\text{max}}$)**:
   $$F_{\text{gap}} = \begin{cases} 25, & \text{если дневной разрыв между слотами еды } > 5.5\text{ ч} \\ 0, & \text{иначе} \end{cases}$$

$$S_{\text{behavior}} = \text{clamp}(F_{\text{protein}} + F_{\text{latency}} + F_{\text{gap}}, \; 0, \; 100)$$

---

#### Шкала риска и системные триггеры:

| Диапазон BRTS | Зона риска | Клинический статус | Автоматическое действие Health Agent |
| :---: | :---: | :--- | :--- |
| **0 – 34** | 🟢 **GREEN** | Стабильный гомеостаз | Обычный ход протокола, плановый дефицит. |
| **35 – 64** | 🟡 **YELLOW** | Диетическая усталость | Гардрейл `BINGE_WARNING`. Проактивная рекомендация: закрыть норму белка в текущем приеме, увеличить сложные углеводы на +200 ккал, лечь спать на 45 минут раньше. |
| **65 – 100** | 🔴 **RED** | **Предсрывной криз** | Гардрейл `BINGE_RISK_CRITICAL`. Автоматический вызов `refeed`: поднятие калоража на 24–48 часов до **100% TDEE**. Активация скрипта проактивного пуша, переключение диалогового бота в режим поддержки и протокола Urge Surfing. |

## 3. Психология и физиология преодоления весового плато

### 3.1. Водная задержка (кортизол-опосредованная гидратация и эффект «Whoosh»)

#### Биохимический механизм феномена «Whoosh»
Одна из главных причин демотивации и панического срыва у худеющих — **весовое плато при сохранении реального окисления жира**.

```
Дефицит калорий + Нагрузки = Хронический стресс
                     │
                     ▼
       Активация оси HPA (Гипоталамус-Гипофиз-Надпочечники)
                     │
                     ▼
       Гиперсекреция базального кортизола
                     │
         ┌───────────┴───────────┐
         ▼                       ▼
Связывание с MR-рецепторами   Липолиз триглицеридов из адипоцитов
в дистальных канальцах почек   (ТГ расщепляются на глицерин и ЖК)
         │                       │
         ▼                       ▼
Задержка ионов Na+ и воды     Адипоцит временно поглощает воду,
в сосудистом и интерстиции    сохраняя объем клетки и цитоскелет
         │                       │
         └───────────┬───────────┘
                     ▼
    ВЕС НА ВЕСАХ СТОИТ (ИЛИ РАСТЕТ НА 0.5-1.5 КГ)
    Жир сгорел, но замаскирован внеклеточной водой
                     │
                     ▼
     Снятие стресса (Рефид / Сон 8-9 ч / Психоразгрузка)
                     │
                     ▼
    Резкий спад кортизола → Вазодилатация и блок MR-рецепторов
                     │
                     ▼
           ЭФФЕКТ «WHOOSH»
    Массивный ночной диурез → Падение веса на 1.5–3 кг за 36 часов!
```

- **Осмотическая модель адипоцита**:
  - Адипоцит не «схлопывается» мгновенно при мобилизации триглицеридов. Чтобы предотвратить коллапс клеточного каркаса, клетка временно закачивает воду.
  - Плотность воды ($1.0 \text{ г/см}^3$) выше плотности нейтрального жира ($0.92 \text{ г/см}^3$). В момент удержания воды объем жировой ткани может временно оставаться прежним или слегка увеличиваться.
- **Дифференциальная диагностика в Health Agent System**:
  - *Истинное плато (метаболическая адаптация)*: вес стоит $\ge 14$ дней, обхваты тела (талия, бедра) не меняются, калораж де-факто сравнялся с фактическим TDEE.
  - *Псевдоплато (кортизоловая задержка)*: вес стоит 7–12 дней, но **обхват талии уменьшается на 1–2 см**, биоимпеданс показывает рост доли воды (`water_pct` $\uparrow$) и сохранение тощей массы.
- **Психологическая ловушка плато**:
  - При виде остановившейся стрелки весов пользователь делает ложный вывод: *«Диета сломалась, метаболизм встал»*.
  - Типичная паническая реакция: урезать калории еще сильнее (до 800–1000 ккал) и добавить час кардио.
  - Результат: кортизол взлетает до пиковых значений, задержка воды усугубляется, разрушается сухая масса $\to$ через 4–6 дней следует тяжелый компульсивный срыв.
  - **Задача бота**: превентивно дать психообразование об эффекте «Whoosh», заблокировать попытки снизить калораж ниже BMR и назначить углеводный рефид для нормализации кортизола.

### 3.2. Управление ожиданиями пользователя при терапии GLP-1 / GIP (Тирзепатид, Семаглутид)

Внедрение агонистов GLP-1/GIP кардинально меняет фармакотерапию ожирения, но создает специфические когнитивные искажения, требующие ювелирной психотерапевтической работы.

#### Клиническая траектория массы тела на GLP-1 (клинические исследования SURPASS и SURMOUNT)

```
Темп потери веса (кг/нед)
 │
3.0│ █  (Фаза 1: Недели 1-4)
   │ █  Вода + Гликоген + Обвал объема пищи в ЖКТ
2.0│ ██
   │ ██ █
1.0│ ██ █ █  (Фаза 2: Недели 5-16)
   │ ██ █ █ █ █  Стабильное окисление жира (0.5 - 1% массы/нед)
0.5│ ██ █ █ █ █ █ █ █  (Фаза 3: Недели 16-24+)
   │ ██ █ █ █ █ █ █ █ █ █  Адаптация рецепторов, асимптотическое плато
0.0└──┴──┴──┴──┴──┴──┴──┴──┴──┴──► Время (недели)
```

#### Три критических когнитивных искажения на GLP-1:

1. **Иллюзия постоянства стартового темпа**:
   - *Проблема*: В первые 2–4 недели пациент теряет 4–8 кг (гликоген, интерстициальная вода, опорожнение кишечника из-за замедления моторики и резкого падения объема порций). Пациент принимает этот аномальный темп за «новую норму».
   - *Кризис недели 6–8*: Когда темп закономерно снижается до физиологических 500–800 г в неделю, возникает паника: *«Лекарство выдохлось, оно больше не действует!»*.
   - *Коррекция агентом*: Формирование реалистичных ожиданий ДО начала или на 2-й неделе. Объяснение, что потеря более 1.0% массы тела в неделю после первого месяца — это прямой маркер потери мышечной ткани и риска саркопении.

2. **Синдром дозовой гонки (Dose Escalation Trap)**:
   - *Проблема*: При первом же естественном замедлении темпа пациент требует досрочно поднять дозировку (например, перейти с 5 мг на 7.5 или 10 мг Тирзепатида раньше протокольного 4-недельного шага).
   - *Последствия*: Резкий рост побочных эффектов (гастропарез, тошнота, рвота, дегидратация, запоры), падение потребления белка ниже критических 0.8 г/кг, катастрофический катаболизм мышечной массы (до 40% от общей потери веса по данным DXA).
   - *Коррекция агентом*: Правило жесткого следования инструкции по титрации. Запрет на досрочное повышение дозы при сохранении планового дефицита.

3. **Возвращение «пищевого шума» vs Здоровый аппетит**:
   - *Проблема*: В первые недели GLP-1 полностью стирает любые мысли о еде (*food noise suppression*). Через 2–3 месяца происходит частичная десенситизация рецепторов гипоталамуса, и к человеку возвращается легкое ощущение голода перед запланированным приемом пищи. Пациент пугается: *«Ко мне вернулся жор!»*.
   - *Коррекция агентом*: Психообразование: цель GLP-1 терапии — не перманентный паралич пищеварительной системы и отвращение к еде, а **восстановление нормальной физиологической регуляции сытости**. Голод за 30–45 минут до обеда — это здоровый признак живого организма. Задача — научиться выбирать пищу в условиях нормального, а не выключенного аппетита.

## 4. Архитектурная интеграция в Health Agent System

### 4.1. Расширение System Prompt (`Core/system_promt.md`)

Ниже приведены готовые модули инструкций для включения в основной системный промпт LLM бота:

```markdown
**[BEHAVIORAL THERAPY & OARS INTERACTION]**
Вы ведете диалог по протоколу доказательной поведенческой терапии (CBT-E, ACT, OARS).
1. **Запрет менторского и инфантилизирующего тона.** Никаких «Молодец!», «Отлично справляешься!», «Так держать!», каскадов эмодзи. Теплота — это объективная польза, эмпатичное принятие и структурная опора.
2. **Отсутствие моральных оценок еды.** Еда не бывает «хорошей» или «плохой», «чистой» или «грязной». Еда — это нутриенты и энергия. Переедание — это не «срыв» и не «слабость воли», а измеримый биологический маркер накопленной усталости, дефицита сна или избыточного ограничения калорий.
3. **Протокол OARS при отклонениях от плана:**
   - Не задавать закрытых обвинительных вопросов («Почему не залогировал обед?»).
   - Отражать амбивалентность: признавать эмоциональную усталость человека и одновременно напоминать о его долгосрочных ориентирах.
   - Валидировать факт честной фиксации: «Ты внес этот вечерний прием полностью. Это сильный навык взрослого контроля: мы оперируем фактами, а не догадками».
   - Передавать автономию выбора человеку: «Данные учтены. Какой шаг ты считаешь наиболее комфортным на завтра?».

**[URGE SURFING & ACT DEFUSION]**
При острой тяге к еде или предсрывном состоянии пользователя:
1. Не давать советов «выпей воды» или «отвлекись». Активировать протокол **Urge Surfing**:
   - Шаг 1: Предложить заметить и соматизировать тягу («Где именно в теле ты ее чувствуешь? Оцени интенсивность от 1 до 10»).
   - Шаг 2: Включить технику когнитивного разделения (Defusion): «Это всего лишь мысль. Мозг предлагает легкий дофамин, потому что устал. Ты не равен своей мысли».
   - Шаг 3: Предложить паузу на 15 минут: дать волне тяги достичь пика и пойти на спад. Если через 15 минут голод останется физиологическим — помочь спокойно и взвешенно включить продукт в КБЖУ дня без чувства вины.

**[PLATEAU & WHOOSH PSYCHOEDUCATION]**
1. При жалобах «вес встал», «уже неделю нет прогресса»:
   - Сверить данные: проверить тренд обхватов (`anthropometry`) и задержку воды (`body_metrics`).
   - Объяснить физиологию водной задержки: дефицит калорий — это кортизоловый стресс. Адипоциты при сжигании жира временно удерживают воду (эффект Whoosh). Снижение веса на весах идет ступеньками, а не линейно.
   - Категорически пресекать панические предложения урезать калории ниже безопасного пола (`BMR_FLOOR` / `undereating`). Решением плато является дисциплина текущего дефицита либо плановый углеводный перерыв (`refeed`), а не голод.

**[GLP-1 EXPECTATION MANAGEMENT]**
1. На терапии GLP-1/GIP (Тирзепатид/Семаглутид):
   - Замедление темпов после первого месяца (с 2–3 кг/нед до 0.5–0.8 кг/нед) объяснять как обязательный физиологический переход: ушла первичная вода и гликоген, началось чистое сжигание жира.
   - Возвращение легкого аппетита перед едой трактовать как здоровье, а не как «отказ препарата».
   - Требования досрочно поднять дозу отклонять: протокол титрации защищает от потери мышечной массы и гастропареза.
   - Акцент на белке: при подавленном аппетите недобор белка ведет к саркопении. Фокус — не на ограничении калорий, а на доборе нормы белка (1.6–2.0 г/кг сухой массы).
```

### 4.2. Конкретные сценарии диалога: Антипаттерн vs Протокол Health Agent

#### Сценарий 1: Пользователь сорвался вечером на фастфуд/сладкое
- **Пользователь**: *«Я все испортил. Пришел домой, накрыло, сожрал целую пиццу и пачку печенья. Наверное, тысячи на две калорий. Я безвольная скотина, все насмарку, руки опускаются».*

❌ **Антипаттерн (как нельзя)**:
> «Ну зачем же ты так? Ты ведь так хорошо шел! Не расстраивайся, соберись с силами, ты же сильный! Завтра ничего не ешь до вечера или сходи на кардио, сожги эти калории. Больше так не делай!»
*(Ошибки: менторство, обесценивание эмоций, токсичный позитив, поощрение компенсаторного расстройства пищевого поведения).*

✅ **Протокол Health Agent (CBT-E + OARS)**:
> «Давай выдохнем. Никакой катастрофы не произошло, и ни о каком "все насмарку" речи нет. 
> 
> Во-первых, один вечер физически не может вернуть сожженный жир: чтобы набрать 1 кг чистого жира, нужен чистый профицит в 7700 ккал сверх расхода. Бо́льшая часть завтрашней прибавки на весах будет обычной водой, связанной гликогеном и солью.
> Во-вторых, давай внесем съеденное в `log_food`. Примерный состав и граммы — сделаем честный факт дня. Мы управляем тем, что оцифровано.
> 
> По графику за последние 5 дней: дефицит превышал 35% при сне по 5.5 часов. Твоя нервная система просто защитила себя от истощения самым быстрым источником энергии. Это биология, а не слабая воля.
> 
> Завтра: никаких голодовок, никаких наказаний тренировками. Обычный плановый завтрак с акцентом на белок и сложные углеводы, чтобы стабилизировать сахар и грелин. Как ты сейчас себя чувствуешь физически?»

#### Сценарий 2: Острая тяга в моменте (Urge Surfing)
- **Пользователь**: *«Сижу на работе, дико тянет пойти к автомату и купить сникерс. Прямо трясет, не могу сосредоточиться».*

❌ **Антипаттерн**:

✅ **Протокол Health Agent (ACT Urge Surfing)**:
> «Зафиксируй этот момент. То, что происходит прямо сейчас — это просто нейрохимическая волна, скачок дофаминового запроса.
> 
> 1. Сделай медленный вдох носом на 4 секунды и длинный плавный выдох через рот на 6 секунд.
> 2. Где в теле эта тяга? Во рту, в челюсти, в солнечном сплетении? Оцени ее накал от 1 до 10.
> 3. Мы не запрещаем тебе этот сникерс. Мы просто не берем его на автомате. Ставим таймер на 15 минут. Волна тяги всегда имеет пик в 10–12 минут, а затем физиологически идет на спад.

> Давай дадим ей эти 15 минут. Если через 15 минут потребность останется реальной — мы спокойно впишем его в бюджет и съедим осознанно. Напиши мне ровно через 15 минут, сколько баллов осталось».

### 4.3. Алгоритмический модуль для `health_core/guards.py`

Для полной совместимости с ядром системы привожу детерминированный код гардрейла `check_binge_risk` для внедрения в `health_core/guards.py`:

```python
# ---------------------------------------------------------------- BINGE_RISK
def check_binge_risk(conn: sqlite3.Connection, user_id: int) -> dict | None:
    """Оценка триады риска срыва (BRTS) на основе дефицита, сна и телеметрии логов.
    
    Детерминированный гардрейл. Срабатывает при накоплении критической комбинации
    метаболического голода, депривации сна и пропусков белка.
    """
    cfg = _cfg()
    today = _now().date()
    today_str = today.isoformat()
    
    # 1. Анализ метаболического дефицита за binge_window_days (умолчание 5 дней)
    window_days = cfg.get("binge_window_days", 5)
    deficit_threshold = cfg.get("binge_deficit_kcal", 3500)
    
    cum_deficit = 0.0
    valid_intake_days = 0
    extreme_deficit_days = 0
    
    for i in range(1, window_days + 1):
        d_str = (today - timedelta(days=i)).isoformat()
        
        # Получаем цель на день
        t_row = conn.execute(
            "SELECT kcal_target FROM daily_targets WHERE user_id=? AND date=?",
            (user_id, d_str)
        ).fetchone()
        
        # Получаем фактическое потребление
        i_row = conn.execute(
            "SELECT COUNT(*) n, COALESCE(SUM(fi.kcal), 0) kcal "
            "FROM food_log fl "
            "JOIN food_items fi ON fi.food_log_id = fl.id "
            "WHERE fl.user_id=? AND date(fl.eaten_at)=?",
            (user_id, d_str)
        ).fetchone()
        
        if i_row and i_row["n"] > 0 and t_row and t_row["kcal_target"]:
            valid_intake_days += 1
            intake = i_row["kcal"]
            target = t_row["kcal_target"]
            day_deficit = max(0.0, target - intake)
            cum_deficit += day_deficit
            if intake < 0.65 * target:
                extreme_deficit_days += 1

    # Нет данных за большинство дней — гардрейл молчит
    if valid_intake_days < 3:
        return None

    # Фактор 1: Глубокий накопленный дефицит
    factor_deficit = (cum_deficit >= deficit_threshold) or (extreme_deficit_days >= 3)
    
    # 2. Анализ сна последней ночи
    sleep_min_threshold = cfg.get("binge_sleep_min", 390)  # 6.5 часов
    last_night = (today - timedelta(days=1)).isoformat()
    
    sleep_row = conn.execute(
        "SELECT duration_min FROM sleep_log WHERE user_id=? AND night_date IN (?, ?)",
        (user_id, today_str, last_night)
    ).fetchall()
    
    factor_sleep = False
    actual_sleep_min = None
    if sleep_row:
        # Берем самый свежий доступный замер
        actual_sleep_min = sleep_row[-1]["duration_min"]
        if actual_sleep_min and actual_sleep_min < sleep_min_threshold:
            factor_sleep = True

    # 3. Анализ утреннего белка (сегодня)
    p_threshold = cfg.get("binge_breakfast_protein_g", 20.0)
    bf_row = conn.execute(
        "SELECT COALESCE(SUM(fi.protein_g), 0) p "
        "FROM food_log fl "
        "JOIN food_items fi ON fi.food_log_id = fl.id "
        "WHERE fl.user_id=? AND date(fl.eaten_at)=? AND fl.meal_slot='breakfast'",
        (user_id, today_str)
    ).fetchone()
    
    factor_protein = False
    breakfast_p = bf_row["p"] if bf_row else 0.0
    # Считаем фактор активным только если наступило время после 11:00 и белка мало
    if _now().hour >= 11:
        if breakfast_p < p_threshold:
            factor_protein = True

    # Подсчет активных факторов риска
    active_factors = sum([1 for f in [factor_deficit, factor_sleep, factor_protein] if f])
    min_factors_trigger = cfg.get("binge_min_factors", 2)

    if active_factors >= min_factors_trigger:
        details = []
        if factor_deficit:
            details.append(f"накопленный дефицит {cum_deficit:.0f} ккал за {valid_intake_days} дн.")
        if factor_sleep and actual_sleep_min:
            details.append(f"сон {actual_sleep_min // 60} ч {actual_sleep_min % 60} мин")
        if factor_protein:
            details.append(f"белок на завтрак {breakfast_p:.0f} г (<{p_threshold:.0f} г)")

        severity = "critical" if (active_factors == 3 or cum_deficit > 4500) else "warning"
        msg = f"Высокий риск срыва (Триада {active_factors}/3): " + "; ".join(details) + "."
        
        return _alert("BINGE_RISK", severity, msg, active_factors, min_factors_trigger)

    return None
```
