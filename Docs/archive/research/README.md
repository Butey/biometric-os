# Каталог исследований: Health Agent System («Метаболический контур»)

Данная папка содержит исчерпывающие материалы глубокого исследования предметной области, архитектуры, научной литературы, вычислительных библиотек и психологических протоколов для проекта **Health Agent System**.

Исследование проведено автономным роем специализированных агентов с последующей оценкой и синтезом через коллегию **llm-council**.

## 🔬 Обзор направлений исследований

### 1. [01. Плагины, базы продуктов питания, трекеры и OCR](file:///opt/webapps/health_agent_system/research/01_agent_plugins_hardware_api.md)
* **Агент:** Hardware, API & MCP Researcher
* **Ключевые находки:**
  * **Open Food Facts (OFF):** Бесплатная открытая база (>3 млн продуктов), превосходное покрытие РФ/СНГ (EAN 460–469), встроенный индекс ультра-обработки NOVA 4 и клетчатки. Нагрузка на RAM < 5 МБ через асинхронный HTTP-клиент.
  * **USDA FoodData Central:** Эталон аминокислотного состава (лейцин) и микронутриентов для базовых цельных продуктов.
  * **Умные весы и трекеры:** Withings Webhooks для мгновенной фиксации состава тела (LBM/жир) без поллинга. Oura API v2 для трекинга фаз сна и HRV.
  * **CGM (глюкоза):** Интеграция с Nightscout API и легковесный Python-клиент `pydexcom` для Dexcom G6/G7.
  * **Аудит OCR для 1GB RAM:** Жесткий запрет локальных PaddleOCR, Nougat и Unstructured (гарантированный OOM Crash). Рекомендован гибридный контур: векторные PDF через `PyMuPDF` (15 МБ RAM, 30 мс) + фото/сканы через облачный Vision LLM API ($0.001 за бланк).

### 2. [02. Медицинские скиллы, архитектурные паттерны и Guardrails](file:///opt/webapps/health_agent_system/research/02_agent_skills_and_frameworks.md)
* **Агент:** Skills & Architectures Researcher
* **Ключевые находки:**
  * **Каталоги открытых скиллов:** Harvard MIMS `ToolUniverse` (698 инструментов), `Open-Medica` (747 клинических алгоритмов), `OpenClaw` (869 фармакологических скиллов).
  * **Dual-System Architecture:** Строгий запрет на выполнение арифметики нейросетью. LLM отвечает за семантику, диалог и Tool Calling. Вся арифметика — детерминированный Python 3.11 со схемами Pydantic V2.
  * **Готовые контракты Pydantic V2:** Разработаны схемы входов и выходов для HOMA-IR, TyG Index, eGFR (CKD-EPI 2021), Cockcroft-Gault с коррекцией веса при ожирении (ABW), GLP-1 Kinetics и Binge Risk Triad.
  * **5-уровневая модель безопасности:** От базового велнеса (Level 1) до экстренного медицинского триажа (Level 5).

### 3. [03. Клиническая литература, эндокринология и метаболическая биофизика](file:///opt/webapps/health_agent_system/research/03_agent_clinical_literature_and_models.md)
* **Агент:** Clinical Literature Researcher
* **Ключевые находки:**
  * **Фармакотерапия тирзепатидом (GIP/GLP-1):** Фармакокинетический пик 24–48 ч (окно максимальной тошноты и снижения моторики ЖКТ), $t_{1/2} = 5.0$ суток, равновесная концентрация $C_{ss}$ за 4 недели.
  * **Потеря мышечной массы (LBM):** По данным SURMOUNT-1 и STEP-1, без силовых тренировок и избытка белка до 25–40% снижения веса приходится на скелетную мускулатуру.
  * **Протокол защиты LBM:** Норма белка строго на тощую массу: **1.6–2.2 г/кг FFM**, лейциновый порог 2.7–3.5 г на порцию, силовые тренировки 2–3 раза/нед, креатин моногидрат 3–5 г/сут.
  * **Модель Кевина Холла (NIH, Lancet 2011):** Дифференциальные уравнения динамического баланса. Правило Форбса $\alpha(F) = 10.4 / (10.4 + F)$ — с падением жировой массы доля потери мышц резко возрастает.
  * **Модель Германа Понтцера (Science 2021):** Constrained TEE Model. Энергетическая компенсация у лиц с ожирением достигает 45–50% (сожженные 100 ккал дают лишь 50 ккал реального расхода).
  * **Предел Сеймура Альперта (2005):** Максимальная отдача энергии жировой ткани человека составляет **$69.3 \pm 6.0\text{ ккал/кг жира/сутки}$** (в кодовой базе найдена и исправлена ошибка перевода 31 ккал/фунт).
  * **Протокол MATADOR (Byrne et al., 2018):** Цикл 2 недели дефицита / 2 недели поддержания снижает адаптивный термогенез в 2.1 раза и увеличивает потерю чистого жира на +54%.

### 4. [04. Вычислительные библиотеки и математические движки](file:///opt/webapps/health_agent_system/research/04_agent_opensource_engines_and_libraries.md)
* **Агент:** Open Source Engines & Mathematical Libraries Researcher
* **Ключевые находки:**
  * **Pure Python PMC Engine:** Реализован легковесный модуль расчета CTL (Fitness), ATL (Fatigue), TSB (Form), Banister TRIMP и ACWR (Acute:Chronic Workload Ratio) без C++ зависимостей GoldenCheetah.
  * **Парсинг телеметрии:** `fitdecode` для .FIT-файлов (12 МБ RAM) и потоковый `iterparse` для TCX и Apple Health XML (защита от краша при гигабайтных выгрузках).
  * **HRV без тяжелого NeuroKit2:** Расчет RMSSD, SDNN и pNN50 на чистом Python прямо из массива RR-интервалов умных часов (<0.1 МБ RAM).
  * **Фармакокинетический движок `TirzepatidePK`:** Аналитическое решение 1-камерной модели с абсорбцией 1-го порядка для расчета текущей концентрации в нг/мл по таблице `med_log`.
  * **Оптимизация корзины (PuLP MILP):** Решение модифицированной задачи Стиглера с ограничением насыщенных жиров $\le 10\%$, порогом белка, калия и клетчатки при потреблении RAM всего 18–25 МБ.

### 5. [05. Поведенческая психология, предикторы срывов и преодоление плато](file:///opt/webapps/health_agent_system/research/05_agent_behavioral_psychology_and_adherence.md)
* **Агент:** Behavioral Psychology Researcher
* **Ключевые находки:**
  * **CBT-E (Christopher Fairburn):** Регулярное питание (3 приема + 2 перекуса, интервал не более 3–4 ч) как физиологический якорь против дихотомического срыва (Abstinence Violation Effect).
  * **ACT Urge Surfing (Alan Marlatt):** Пошаговый диалоговый протокол серфинга тяги (15-минутная экспозиция) и когнитивное разделение («Пассажиры в автобусе»).
  * **Мотивационное интервьюирование (OARS):** Запрет менторского тона и токсичного позитива («Молодец!»). Эмпатичное отражение амбивалентности и возвращение автономии пользователю.
  * **Binge Risk Triad Score (BRTS):** Детерминированная формула интегральной оценки угрозы срыва (0–100 баллов):
    $$\text{BRTS} = 0.40 S_{\text{deficit}} + 0.30 S_{\text{sleep}} + 0.30 S_{\text{behavior}}$$
    При BRTS > 65 баллов активируется предупреждение и автоматический защитный рефид.
  * **Эффект «Whoosh»:** Кортизол-опосредованная задержка воды в жировых клетках при окислении триглицеридов. Психообразование против паники и ужесточения диеты на плато.
