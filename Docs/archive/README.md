# Архив проекта

Материалы сохранены для истории и не определяют текущую архитектуру.
Актуальные инструкции: [README](../../README.md), [DEPLOY](../../DEPLOY.md),
[рабочая архитектура](../bot_design.md).

Из корня проекта сюда перенесены `SPEC.md`, `ТЗ.txt`, `agy.md`,
`_agent_swarm_analysis/`, `gemini_edited/`, `llm-council/`, `research/`,
`audit_results/`, `economy/`, `Weightloss Analyzer/`, `Обучение/`
и `claude-token-efficient`.

В `hermes/` сохранены прежний внешний манифест `plugin.yaml`, руководство
`installation_reference.md` (бывший `Docs/install.md`) и `reference/`
(бывший `Docs/hermes_ref/`). Их команды не нужны для запуска бота.
`DEPLOY_before_project_layout.md` и `bot_design_before_project_layout.md` —
снимки документации до переноса настроек в проект.

Внутренние ссылки в исторических материалах могут указывать на прежние пути.
