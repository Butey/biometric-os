# Ревизия поведения по восстановленной истории

Дата: 7 ноября 2026 года. Основание — фрагменты диалога из семи резервных
копий и сопоставление аргументов инструментов с фактически сохранёнными данными.
Автоматические сводки и прошлые ответы модели не использовались как доказательство
медицинских причин или актуального состояния.

## Исправления

| Наблюдавшаяся ошибка | Изменение | Проверка |
|---|---|---|
| Дата прошлой инъекции заменялась датой сообщения | Существующая проверка прошлых дней недели и исправление по ID сохранены; фактическая дата присутствует в подтверждении | Регрессии лекарственного журнала |
| Утреннее измерение называлось вечерним | `query_metrics` возвращает полный `measured_at`, местное `as_of`; будущие записи исключаются | `test_review_query_metrics_keeps_timestamp_and_excludes_future` |
| Две крайние точки использовались вместо проверки плато; FFM называлась потерей мышц | `get_trends` возвращает общую оценку динамики; `lean_loss` содержит собственные числитель, знаменатель, метод и признак отсутствия прямого измерения мышц | Существующие проверки плато и FFM; правила обычного диалога и консилиума |
| Восемь пригодных для расчёта тренировок выдавались за все тренировки | Отдельные `total_sessions`, `usable_sessions`, `excluded_sessions` | Проверки тренировочных сводок |
| Частичный сегодняшний рацион менял расход и цель питания | Обе адаптивные оценки используют завершённые дни; повторные утренние измерения сначала сворачиваются в дневную медиану | `test_review_partial_today_does_not_recalibrate_expenditure` |
| Цифры ошибочно распознанной этикетки переносились на другой продукт | Валидация чисел и массы нутриентов; защита от резкого изменения сохранённой этикетки; неизвестные поля частичного обновления сохраняют прежнее значение | `test_review_product_validation_and_label_conflict` |
| Модель могла изменить состав сохранённого продукта при записи еды | Для `source=my_product` числа читаются из справочника, а не принимаются из пересказа модели; ответ `remember` показывает фактически сохранённую карточку | `test_review_my_product_uses_saved_macros_and_confirms_actual_source` |
| Частичное обновление часов создавало `hr_min > hr_avg` или противоречивый SpO2 | Проверяется объединённая запись; противоречивые старые дни исключаются из блока трендов; покрытие считается по каждому показателю | `test_review_watch_partial_updates_validate_merged_record` |
| Ошибка одного дня в пакете выдавалась как успешная запись всего пакета | `saved_days`/`rejected_days`, общая ошибка при полном отказе, предупреждение при частичном успехе | Та же регрессия часов |
| Сон был длиннее интервала между отбоем и подъёмом | Проверяются часы, объединённая запись и сумма глубокого/REM-сна до записи | `test_review_sleep_rejects_impossible_time_and_preserves_previous` |
| Посторонняя роль попадала в сжатую историю | Отбрасываются известные маркеры чужой роли; невалидная сводка не заменяет исходные сообщения и не загружается из старой базы | `test_review_foreign_identity_summary_is_rejected_and_not_loaded` |
| Очистка контекста удаляла единственный экземпляр переписки | Перед очисткой используется существующий атомарный JSON-архив | Та же регрессия истории |
| Сбой сжатия мог прервать новое сообщение | Ошибки проверки сводки, архива и SQLite обрабатываются без остановки обычного хода | `test_review_bad_compaction_does_not_drop_new_message` |
| Однозначная запись воды зависела от модели | Полностью совпавшее сообщение о выпитой воде записывается напрямую; вопросы и указания прошлого времени идут в диалог | `test_review_simple_water_is_recorded_without_model_but_questions_are_not` |
| Пустой ответ модели оставлял человека без результата | Возвращается понятное уведомление с указанием проверить журнал перед повторной записью; внутренние рассуждения не публикуются | Регрессия reasoning-only ответа и самопроверка `bot.llm` |

## Договорённости о данных

- Дата события отделена от даты сообщения; время инструмента местное для пользователя.
- Справочник и журнал являются источниками чисел. Результат записи показывает сохранённые данные.
- Отсутствие показателя не подменяется нулём; частичное обновление проверяется вместе с сохранёнными полями.
- Завершённый календарный день не означает подтверждённую полноту дневника. Оценки расхода по-прежнему зависят от точности записей.
- Ошибка проверки не создаёт запись и не меняет запасы. В пакете часов возможен явно обозначенный частичный успех.
- Сжатие и очистка контекста сохраняют оригиналы в приватном архиве; архив не подмешивается целиком в контекст модели.
- Углеводы не называются сахаром. Суточные колебания не получают доказанную причину без данных; внутренние пороги не называются клинической нормой.

## Изменение личных данных

После резервного копирования удалена одна подтверждённо ошибочная общая карточка
продукта. Корректная более конкретная карточка сохранена. Журнал съеденного,
история веса, воды, препаратов и переписка при этой операции не изменялись.
Аудит операции и резервная копия находятся вне репозитория.

## Проверки

- `python test_bot.py`: 100 проверок, 0 ошибок, включая 9 новых сценариев.
- `python test_e2e.py`: все этапы пройдены на локальных фикстурах и временной БД.
- Самопроверки `health_core.foods`, `health_core.watch`, `health_core.energy`,
  `health_core.report`, `bot.history`, `bot.llm`, `bot.council`: пройдены.
- В самопроверке энергии зафиксированы настройки синтетических сценариев,
  расширен заведомо достижимый тестовый срок и сдвинуты пищевые фикстуры на
  завершённые дни. Рабочие настройки калорийности не менялись.
- Зависимости проекта не добавлялись. Проверки выполнялись в отдельной временной
  среде Python 3.14, без сети к Telegram и провайдерам модели.

## Ограничения

Математические и структурные проверки не доказывают правильность распознавания
фото. Резкая смена этикетки — сигнал перепроверить продукт, а не доказательство
ошибки. Семантические правила ответа модели и консилиума не являются формальной
гарантией отсутствия галлюцинаций; внешние вызовы реальных моделей в этой ревизии
не выполнялись. Старые сомнительные пищевые значения без исходной этикетки не
пересчитывались. Сервисы не перезапускались.
