# Документация проекта

## Актуальные инструкции

- [README](../README.md): структура, локальный запуск, данные, история и экспорт.
- [DEPLOY](../DEPLOY.md): установка, миграция из старого каталога, systemd и резервирование.
- [Рабочая архитектура](bot_design.md): границы компонентов и источник настроек.
- [Карта проекта](../PROJECT_MAP.md): навигация по коду.
- [Настройки LLM](llm_config.md) и [TLS-прокси панели](../admin/README-proxy.md).

Секреты находятся в `.env` проекта, SQLite — по умолчанию в `health.db` проекта.
Рабочий runtime — собственный aiogram-бот; установка Hermes не требуется.
`plugin/` содержит локальные инструменты, а не подключение к внешнему шлюзу.

## Аудиты и исторические материалы

[Архитектурное ревью](architecture_review_2026-11-07.md) и
[код-ревью](code_review_2026-11-07.md) описывают проверки на указанную дату;
списки ограничений и числа тестов в них относятся к соответствующему этапу.
`code_analysis/`, `skills_analysis/`, `migration_spec.md` и `architecture.html`
содержат более ранние анализы и проекты решений, а не инструкции развёртывания.

[archive/](archive/) сохраняет старые спецификации, исследования, черновики
агентных запусков и справочные материалы Hermes. Исторические пути и команды
внутри этих документов могут быть неактуальны. Перемещения перечислены в
[указателе архива](archive/README.md).
